List of Plugins
- Interactions (own implementation with pointer events, jQuery UI compatible API): draggable, droppable, resizable, sortable
- MouseWheel (https://github.com/jquery/jquery-mousewheel)
- Input Mask (https://github.com/RobinHerbots/Inputmask)
- Rangy Text (https://github.com/timdown/rangy)
- Cursor Position (https://github.com/beviz/jquery-caret-position-getter)
- Browser (https://github.com/gabceb/jquery-browser-plugin/releases)
- Autosize (https://github.com/jackmoore/autosize)

Extensions:

jquery.pfextensions:
- :focusable and :tabbable selectors (formerly jQuery UI)
- Tooltip removal fix (https://github.com/primefaces/primefaces/issues/9941)

interaction/plugins:
- remove event on removed elements ($.cleanData), used to destroy widgets after AJAX updates
- Droppable zoom factor handling (https://github.com/primefaces/primefaces/issues/10689)
