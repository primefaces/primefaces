No third-party jQuery plugins anymore (the mouse wheel uses the native wheel event).

Extensions:

jquery.pfextensions:
- focus(delay, callback): focuses the elements after a delay
- zIndex(): the z-index of the element or its closest positioned parent (formerly jQuery UI)
- :focusable and :tabbable selectors (formerly jQuery UI)
- remove event on removed elements ($.cleanData, formerly jQuery UI), used to destroy widgets and interactions after AJAX updates
  (replaces the $.fn.remove patch of the tooltip removal fix https://github.com/primefaces/primefaces/issues/9941)

The interactions (draggable, droppable, resizable, sortable) are PrimeFaces code in core/src/interaction (PrimeFaces.interactions),
the browser detection (formerly the jQuery Browser plugin) is in core/src/core/core.env.ts (PrimeFaces.env.browser) and the caret
position of the textarea (formerly the jQuery Caret Position plugin) is in the InputTextarea widget.
