TreeTable Edit The data of a TreeTable with editable="true" can be edited at row or cell level, each column defines its display and its input in the output and input facets of a p:cellEditor. Row editing uses a p:rowEditor and fires the Ajax events rowEdit and rowEditCancel, editMode="cell" fires cellEdit. editInitEvent opens a cell with another event, here a double click.
