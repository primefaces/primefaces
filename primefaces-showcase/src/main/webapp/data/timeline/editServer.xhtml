Timeline Editable events and server-side API With editable="true" events can be created by a double click on empty space, edited, moved, resized and deleted; they are only editable when selectable is true. Editable timelines fire the Ajax events select, change, changed, edit, add and delete. The listeners open dialogs to edit or delete a booking, and the bean updates the timeline with the server side TimelineUpdater.
