When PrimeFaces fits, and when it does not

No technology fits every project. Pick the architecture that matches your application and your team.

PrimeFaces is a great fit for

  • Business applications full of forms, tables and workflows: back offices, admin tools, B2B portals
  • Java teams who want one stack from the database to the UI
  • Applications that have to be maintained for many years
  • Security-sensitive domains where logic and data should stay on the server

An SPA may fit better for

  • Applications that have to work offline or with a poor connection
  • Canvas-like UIs such as design tools or editors, where nearly every interaction stays in the browser
  • Public sites with huge numbers of anonymous users, where server-side state per user gets expensive
  • Projects that need a public API anyway (mobile apps, third parties) and have a frontend team in place
