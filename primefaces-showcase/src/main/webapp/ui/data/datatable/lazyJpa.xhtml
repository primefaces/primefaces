DataTable Lazy JPA JPALazyDataModel is a ready-made LazyDataModel for JPA: it turns the paging, sorting and filtering information the DataTable passes to load into a Criteria API query, so none of it happens in memory. Every filter match mode a user picks from a column's dropdown becomes a predicate in the WHERE clause - this table is the Filter example's preset table, filtered in the database instead.
Filtering in the Database

The model is built with a builder, out of the entity class and a supplier for the EntityManager. caseSensitive(false) makes the text match modes compare case-insensitively, as an in-memory filter does; the default is a case-sensitive LIKE.

Two match modes need a word of warning. Matches regex has no portable JPA equivalent, so the model of this example overrides createRegexPredicate with the regex function of its own database (see LazyJpaView.H2LazyDataModel) - without such an override, picking it throws. And the array modes become MEMBER OF predicates, so they need the field to be a mapped collection, as the Tags column below is.

The global filter, on the other hand, is not supported by JPALazyDataModel at all - a global search box would have to be implemented with a filterEnricher of your own - which is why this table has none, unlike the Filter example it mirrors.
