Barcode A QR code (quick-response code) is a type of two-dimensional matrix barcode. It is displayed with p:barcode and type="qr" and is generated using the Okapi library. The demo enlarges the code with magnification. 

            <dependency>
               <groupId>uk.org.okapibarcode</groupId>
               <artifactId>okapibarcode</artifactId>
               <version>0.5.1</version>
            </dependency>
