GraphicImage GraphicImage extends the standard h:graphicImage and can display images created at runtime or stored in a database. The demo shows a static resource image, a StreamedContent loaded in a separate request, a byte array rendered as a data URI with stream="false", a StreamedContent written to the response without buffering, and a text drawn as an image on the server.
