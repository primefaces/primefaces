Media Media is a generic player to embed multimedia content. Players are flash, quicktime, windows media, realplayer and pdf; one is chosen from the file extension or set with player. The demo displays a PDF from a static path and the same PDF as StreamedContent; the content inside the tag is the fallback for browsers that cannot display the PDF.
