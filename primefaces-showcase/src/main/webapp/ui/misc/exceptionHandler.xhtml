ExceptionHandler PrimeFaces provides its own ExceptionHandler with the following features:
  • support for Ajax and non-Ajax requests
  • redirect to the matching error-page configured in web.xml
  • an EL extension called \#{pfExceptionHandler} that provides information about the exception
  • the p:ajaxExceptionHandler component to customize the handling of Ajax exceptions on the current view
