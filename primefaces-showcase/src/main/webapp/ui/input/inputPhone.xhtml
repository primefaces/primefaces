InputPhone InputPhone is an input for international phone numbers with a country selector. The number is formatted while typing and submitted in the E.164 format (e.g. +4930123456), numbers that are not valid for their country are rejected. Formatting and validation are based on libphonenumber-js, on the server Google's libphonenumber is used if it is available.
Basic

The country is selected in the panel or follows a number entered with its calling code (e.g. +44 20 7946 0958).

International Format

With nationalMode="false" the number is shown with its calling code, which is filled in when the empty input gets the focus.
