TriStateManyCheckbox TriStateManyCheckbox is a group of checkboxes with three states each. The value is a Map of the item values to their states: "0" (unchecked), "1" (checked) and "2" (crossed), or objects with a converter.
Basic

A click, Space or Enter moves an item to the next state, the arrow keys move forward and back.
