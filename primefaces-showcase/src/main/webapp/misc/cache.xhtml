Cache Cache reduces the page load time: it stores the rendered output of its content in a region of a cache provider (e.g. Ehcache) after the initial rendering and reuses it afterwards. The showcase uses it for the source code tabs of every page, because parsing an XHTML file takes time and the output does not change while the application runs.
  • tabscode.xhtml demonstrate how to use cache component declaratively
  • ShowcaseUtil demonstrate how to use cache API programmatically
