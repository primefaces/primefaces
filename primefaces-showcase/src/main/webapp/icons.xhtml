PrimeIcons

PrimeIcons is the icon font of PrimeTek. It is part of the PrimeFaces JAR and available on every page, nothing has to be installed.

Getting Started

PrimeIcons use the pi pi-{icon} syntax such as pi pi-check. A standalone icon can be displayed using an element like i or span.


<i class="pi pi-check"></i>
<i class="pi pi-times"></i>

Components

Components with an icon take the same style classes in their icon attribute.


<p:commandButton value="Save" icon="pi pi-check"/>

Size

Size of the icons can easily be changed using the font-size property.


<i class="pi pi-check"></i>
<i class="pi pi-check" style="font-size: 2rem"></i>

Spinning Animation

The pi-spin class applies a continuous rotation to an icon.


<i class="pi pi-spin pi-spinner" style="font-size: 2rem"></i>
