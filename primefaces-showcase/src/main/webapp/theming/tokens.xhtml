Theming Tokens

The design tokens (CSS variables) of the current preset. Change the preset or the tokens on the right, the values follow.

Tokens

All --p-* tokens of the current theme, read at runtime from the loaded stylesheets (rules :root and :root, [data-p-scope], also inside cascade layers), grouped by the prefix after --p-. Declared is the value of the stylesheet, computed the value on <html> with the current color scheme, primary color, density and configurator overrides (marked override). Click a token name to copy var(--p-...).
